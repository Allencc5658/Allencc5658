# AllenCC

I'm exploring embodied intelligence.
My current open-source work focuses on speech tools and evaluation.

## Selected projects

### [CosyVoice-WebSocket](https://github.com/Allencc5658/CosyVoice-WebSocket)

Real-time streaming text-to-speech with CosyVoice over WebSocket.
Includes a Python client and a browser test page.

### [VoiceRecognizor](https://github.com/Allencc5658/VoiceRecognizor)

Text-to-speech quality evaluation with Paraformer speech recognition.
Supports batch evaluation, text comparison, and CER/WER visualization.
